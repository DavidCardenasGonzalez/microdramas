# Continuidad visual y decisión de referencias

La política vigente es el mínimo suficiente de la [guía oficial](AI_FILM_DIRECTION_PLAYBOOK.md), sección 5. Fast Ref y Motion usan imágenes de identidad y continuidad textual, sin hoja maestra ni frames inicial/final obligatorios.

1. Consultar estado, referencias, jobs, clips y cortes existentes; comprobar versiones y hashes.
2. Reutilizar identidad revisada para personajes recurrentes reconocibles. Figuración incidental puede definirse por texto.
3. Conservar set, arquitectura, ropa, iluminación, eje y apariencia de utilería en SequenceContinuity con scope: invariants. Repetir ese canonicalText literalmente; posiciones, manos, propietarios y puertas cambiantes se heredan en Shot.dynamicState.start/end. Planificar la secuencia completa con SequencePlan antes de dividir clips.
4. Crear únicamente una imagen faltante cuyo valor esté justificado: deriva repetida, set con geometría importante, vestuario persistente o necesidad específica de identidad/composición. Aproximadamente seis clips o varios capítulos orientan la decisión, sin cuota rígida.
5. Inspeccionar toda imagen antes de adjuntarla. Registrar roles y sujetos en Reference Plan; el manifest se deriva del estado. No agregar una referencia solo porque existe.

Vestuario breve y set nuevo no obligan a generar imagen. Una hoja puede servir como recurso de planificación cuando aporte valor, sin volverse requisito universal ni frame I2V. Video anterior como referencia queda para una prueba aislada con recursos confirmados.

Cambiar una referencia usada invalida dependientes; informar su efecto antes de hacerlo. Conservar los archivos y reutilizar los que originaron clips existentes. No regenerar cobertura al reanudar.

Para un plan heredado o petición explícita de I2V, usar un primer frame individual real, compatible y revisado. FLF requiere ambos extremos reales. Crear solo el frame faltante con identidad y continuidad pertinentes; una hoja opcional puede orientar, pero nunca sustituye el frame. Estas necesidades de adaptadores heredados no se aplican a Fast Ref/Motion.
